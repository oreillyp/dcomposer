https://github.com/facebookresearch/audiocraft

The upstream MIT code license is preserved in LICENSE. Local modifications
include the standalone VAE wrapper and integration with DComposer's tokenizer API.
The historical source revision is not yet established. Pretrained weights are
not covered by that code license; see upstream LICENSE_weights and model terms.
